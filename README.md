# AL HUD

A modern, lightweight and highly optimized HUD for FiveM ESX Legacy servers.

## ✨ Features

- Modern and responsive NUI
- Advanced speedometer
- Vehicle information
- Health & Armor
- Hunger & Thirst
- Oxygen indicator
- Voice status
- Cash / Bank / Black Money
- Donate Coins
- Society Money
- Main Job & Second Job
- Mafia Support
- Boss Detection
- Postal System
- Configurable logo
- KM/H & MPH support
- Performance optimized
- ESX Legacy compatible

## 📥 Installation

1. Download the latest release.
2. Place the resource inside your `resources` folder.
3. Import the SQL file (if provided).
4. Add the following to your `server.cfg`

```cfg
ensure al_hud
```

5. Configure the resource through `config.lua`.
